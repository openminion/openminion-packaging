# Support

## Current posture

This repository is a private prototype. Its build scripts and temporary CI
artifacts are maintained for engineering evaluation, not as supported public
downloads.

Current evidence covers native prototype construction for macOS ARM64, Linux
x86-64, and Windows x86-64. The certification matrix records which release
requirements remain open.

## Getting help

Include:

1. the packaging commit and target identifier,
2. the exact command or workflow run,
3. the OpenMinion wheel filename and hash,
4. the dependency-wheel filename and hash when used, and
5. the failure output with credentials and private URLs removed.

OpenMinion runtime behavior and Desktop packaging belong to their owning
repositories. Provider outages, host configuration, and unsigned prototype
distribution are outside this repository's support boundary.
